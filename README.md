A secure web application incorporating role-based authentication and authorization to manage distinct user roles effectively with React Query hook for proper redundant for the load on the server.  Admin: Admins has full control over managing property listings, projects, community and developer data, providing them with a streamlined, secure process for maintaining property-related data.  SEO: Users can create and edit blogs using rich-text additionally SEO users can manage metadata and headlines related to all pages, slugs for each page to improve search engine optimization and navigation.  Super Admin: Super Admins has full access to the platform, the ability to create edit and delete user profiles and agents, viewing, tracking creation and update timestamps of all data, assigning roles and managing permissions.  The application served under a custom domain using HTTPS to ensure secure communication between the client and server.  NGINX configured as a reverse proxy, handling traffic routing efficiently while enhancing application security and load balancing.
